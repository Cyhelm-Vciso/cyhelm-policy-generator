# CyHelm Policy Forge

A deterministic security-policy generator with organizational scoping, conditional clauses, document governance metadata, Markdown download, and optional AI language review.

Run `npm start`, then open `http://127.0.0.1:4173`. No AI is required.

Optional AI works with hosted OpenAI-compatible providers, Ollama, or LM Studio. Configure `CYHELM_AI_BASE_URL`, `CYHELM_AI_MODEL`, and an optional `CYHELM_AI_API_KEY` in the server environment.

Generated documents are drafts, not legal advice, and require organization-specific legal, privacy, compliance, and management review.
